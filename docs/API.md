# API Documentation

## Utility Functions

### Logger (`src/utils/logger.js`)

Winston-based logging utility for comprehensive application logging.

#### Functions

##### `logInfo(message, meta)`

Log an informational message.

**Parameters:**
- `message` (string): The message to log
- `meta` (Object, optional): Additional metadata

**Example:**
```javascript
import { logInfo } from './utils/logger.js';

logInfo('Configuration parsed successfully', { config: configData });
```

##### `logWarn(message, meta)`

Log a warning message.

**Parameters:**
- `message` (string): The warning message
- `meta` (Object, optional): Additional metadata

**Example:**
```javascript
import { logWarn } from './utils/logger.js';

logWarn('Menu file not found. Using empty menu.');
```

##### `logError(message, error)`

Log an error message.

**Parameters:**
- `message` (string): The error message
- `error` (Error|Object): Error object or metadata

**Example:**
```javascript
import { logError } from './utils/logger.js';

try {
  // some operation
} catch (err) {
  logError('Failed to parse configuration', err);
}
```

### Config Parser (`src/utils/configParser.js`)

Parses and validates configuration files.

#### Functions

##### `parseConfig(configPath)`

Parse and validate config.yaml file.

**Parameters:**
- `configPath` (string): Path to config.yaml file

**Returns:**
- (Object): Validated configuration object

**Default Values:**
```javascript
{
  title: 'Welcome to BasicBlog',
  theme: 'light',
  output_dir: './build',
  multi_page: false,
  author: '',
  description: 'A blog generated by BasicBlog'
}
```

**Example:**
```javascript
import { parseConfig } from './utils/configParser.js';

const config = parseConfig('./config.yaml');
console.log(config.title); // 'My Blog'
```

##### `parseMenu(menuPath)`

Parse menu.json file.

**Parameters:**
- `menuPath` (string): Path to menu.json file

**Returns:**
- (Array): Array of validated menu items

**Menu Item Structure:**
```javascript
{
  label: string,  // Display text
  url: string     // Link URL
}
```

**Example:**
```javascript
import { parseMenu } from './utils/configParser.js';

const menu = parseMenu('./menu.json');
// [{ label: 'Home', url: '/' }, ...]
```

##### `parseEntries(entriesPath)`

Parse entries.json file.

**Parameters:**
- `entriesPath` (string): Path to entries.json file

**Returns:**
- (Object): Object mapping pane IDs to content arrays

**Entry Structure:**
```javascript
{
  type: 'text' | 'markdown' | 'html',
  content: string,
  title?: string  // Optional
}
```

**Example:**
```javascript
import { parseEntries } from './utils/configParser.js';

const entries = parseEntries('./entries.json');
// { main: [{ type: 'text', content: '...' }], ... }
```

### Panes Parser (`src/utils/panesParser.js`)

Parses panes.cfg file with robust validation.

#### Functions

##### `parsePanes(panesPath)`

Parse panes.cfg file.

**Parameters:**
- `panesPath` (string): Path to panes.cfg file

**Returns:**
- (Array): Array of pane objects

**Pane Object Structure:**
```javascript
{
  name: string,   // Pane identifier (alphanumeric)
  width: number   // Width percentage (0-100)
}
```

**Format:** `|pane_name [width%]|`

**Validation Rules:**
1. Pane names must be alphanumeric (a-z, A-Z, 0-9, -, _)
2. No duplicate pane names
3. Widths must be 1-100
4. Total widths normalized to 100%

**Example:**
```javascript
import { parsePanes } from './utils/panesParser.js';

const panes = parsePanes('./panes.cfg');
// [
//   { name: 'sidebar', width: 25 },
//   { name: 'main', width: 50 },
//   { name: 'footer', width: 25 }
// ]
```

##### `validateEntriesAgainstPanes(entries, panes)`

Validate that entries reference valid panes.

**Parameters:**
- `entries` (Object): Entries object from parseEntries
- `panes` (Array): Panes array from parsePanes

**Returns:**
- (Object): Validated entries with warnings for mismatched panes

**Example:**
```javascript
import { validateEntriesAgainstPanes } from './utils/panesParser.js';

const validEntries = validateEntriesAgainstPanes(entries, panes);
```

## React Components

### Navigation (`src/components/Navigation.jsx`)

Responsive navigation component with theme toggle.

#### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `menuItems` | Array | `[]` | Array of menu item objects |
| `title` | string | `'BasicBlog'` | Blog title |
| `theme` | string | `'light'` | Current theme ('light' or 'dark') |
| `onThemeToggle` | Function | - | Theme toggle handler |

#### Example

```jsx
import Navigation from './components/Navigation';

function App() {
  const [theme, setTheme] = useState('light');
  
  return (
    <Navigation
      menuItems={[
        { label: 'Home', url: '/' },
        { label: 'About', url: '/about' }
      ]}
      title="My Blog"
      theme={theme}
      onThemeToggle={() => setTheme(theme === 'light' ? 'dark' : 'light')}
    />
  );
}
```

### PaneGrid (`src/components/PaneGrid.jsx`)

Renders panes in a responsive grid layout.

#### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `panes` | Array | `[]` | Array of pane objects |
| `entries` | Object | `{}` | Object mapping pane names to entries |

#### Example

```jsx
import PaneGrid from './components/PaneGrid';

function HomePage() {
  const panes = [
    { name: 'sidebar', width: 25 },
    { name: 'main', width: 75 }
  ];
  
  const entries = {
    sidebar: [
      { type: 'text', content: 'Sidebar content' }
    ],
    main: [
      { type: 'markdown', content: '# Hello World' }
    ]
  };
  
  return <PaneGrid panes={panes} entries={entries} />;
}
```

### Button (`src/components/ui/Button.jsx`)

shadcn/ui Button component with multiple variants.

#### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | string | `'default'` | Button variant |
| `size` | string | `'default'` | Button size |
| `className` | string | - | Additional CSS classes |

#### Variants

- `default`: Primary button with shadow
- `destructive`: Red destructive action
- `outline`: Outlined button
- `secondary`: Secondary style
- `ghost`: Transparent background
- `link`: Link-style button

#### Sizes

- `default`: Standard size
- `sm`: Small
- `lg`: Large
- `icon`: Icon-only (square)

#### Example

```jsx
import { Button } from './components/ui/Button';

function MyComponent() {
  return (
    <>
      <Button variant="default">Click me</Button>
      <Button variant="outline" size="sm">Small</Button>
      <Button variant="ghost">Ghost</Button>
    </>
  );
}
```

## CLI

### Commands

#### `basicblog generate [config-dir]`

Generate a blog from configuration files.

**Arguments:**
- `config-dir` (optional): Directory containing config files (default: current directory)

**Options:**
- `-o, --output <dir>`: Override output directory from config.yaml

**Example:**
```bash
# Generate from current directory
basicblog generate

# Generate from examples directory
basicblog generate ./examples

# Override output directory
basicblog generate ./examples -o ./my-blog
```

## Validation Schemas

### Config Schema (Joi)

```javascript
{
  title: Joi.string().required().min(1).max(200),
  theme: Joi.string().valid('light', 'dark').default('light'),
  output_dir: Joi.string().default('./build'),
  multi_page: Joi.boolean().default(false),
  author: Joi.string().optional(),
  description: Joi.string().optional()
}
```

### Menu Item Validation

```javascript
{
  label: string (required),
  url: string (required)
}
```

### Entry Validation

```javascript
{
  type: 'text' | 'markdown' | 'html' (required),
  content: string (required),
  title: string (optional)
}
```

## Error Handling

### Error Types

#### Configuration Errors

**Missing File:**
```
WARN: Configuration file not found at ./config.yaml. Using default configuration.
```

**Invalid YAML:**
```
ERROR: Invalid YAML syntax in config.yaml: unexpected token. Using default configuration.
```

**Validation Error:**
```
WARN: Validation errors in config.yaml: "title" is required. Using defaults for invalid fields.
```

#### Panes Errors

**Duplicate Name:**
```
ERROR: Duplicate pane name 'main' found. Each pane must have a unique name. Skipping duplicate.
```

**Invalid Width:**
```
WARN: Invalid width '150' for pane 'sidebar'. Must be 1-100. Using auto width.
```

**Invalid Name:**
```
WARN: Invalid pane name 'my pane' at position 0. Must be alphanumeric. Skipping.
```

#### Entries Errors

**Invalid Type:**
```
WARN: Entry at index 0 in pane 'main' has invalid type. Skipping.
```

**Missing Content:**
```
WARN: Entry at index 1 in pane 'sidebar' missing valid content. Skipping.
```

**Mismatched Pane:**
```
WARN: Entries reference pane 'footer' which is not defined in panes.cfg. Skipping these entries.
```

## Plugin System

### Plugin Structure

```javascript
// plugins/my-plugin.js
export default function myPlugin(app) {
  // Plugin initialization
  console.log('Plugin loaded');
  
  // Register hooks
  app.on('beforeRender', () => {
    // Custom logic
  });
  
  // Add custom functionality
  app.addComponent('MyComponent', MyComponent);
}
```

### Available Hooks

- `beforeParse`: Before parsing configuration files
- `afterParse`: After parsing configuration files
- `beforeRender`: Before rendering components
- `afterRender`: After rendering components
- `beforeBuild`: Before building for production
- `afterBuild`: After building for production

### Plugin API

```javascript
{
  on(event, callback): void,
  addComponent(name, component): void,
  addRoute(path, component): void,
  extendConfig(config): void
}
```

## TypeScript Support

While BasicBlog is written in JavaScript, you can add TypeScript support:

1. Install TypeScript:
```bash
npm install -D typescript @types/react @types/react-dom
```

2. Create `tsconfig.json`:
```json
{
  "compilerOptions": {
    "target": "ES2020",
    "useDefineForClassFields": true,
    "lib": ["ES2020", "DOM", "DOM.Iterable"],
    "module": "ESNext",
    "skipLibCheck": true,
    "moduleResolution": "bundler",
    "allowImportingTsExtensions": true,
    "resolveJsonModule": true,
    "isolatedModules": true,
    "noEmit": true,
    "jsx": "react-jsx",
    "strict": true,
    "noUnusedLocals": true,
    "noUnusedParameters": true,
    "noFallthroughCasesInSwitch": true
  },
  "include": ["src"],
  "references": [{ "path": "./tsconfig.node.json" }]
}
```

3. Rename `.js` files to `.tsx` or `.ts`

## Performance Optimization

### Code Splitting

Use React.lazy for route-based code splitting:

```javascript
import { lazy, Suspense } from 'react';

const HomePage = lazy(() => import('./pages/HomePage'));

function App() {
  return (
    <Suspense fallback={<div>Loading...</div>}>
      <HomePage />
    </Suspense>
  );
}
```

### Image Optimization

Place images in `public/` directory and reference them:

```javascript
<img src="/images/logo.png" alt="Logo" loading="lazy" />
```

### Bundle Analysis

```bash
npm install -D rollup-plugin-visualizer
```

Add to `vite.config.js`:
```javascript
import { visualizer } from 'rollup-plugin-visualizer';

export default {
  plugins: [
    react(),
    visualizer()
  ]
};
```

## Testing

### Unit Tests

```javascript
// tests/panesParser.test.js
import { parsePanes } from '../src/utils/panesParser';

describe('parsePanes', () => {
  test('parses valid configuration', () => {
    const result = parsePanes('./examples/panes.cfg');
    expect(result).toHaveLength(3);
    expect(result[0].name).toBe('sidebar');
  });
  
  test('handles missing file', () => {
    const result = parsePanes('./nonexistent.cfg');
    expect(result).toEqual([{ name: 'main', width: 100 }]);
  });
});
```

```javascript
// tests/Navigation.test.jsx
import { render, screen } from '@testing-library/react';
```
